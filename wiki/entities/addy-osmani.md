# Addy Osmani

Software engineer and writer who blogs at addyosmani.com on AI-assisted development. Maintainer of **[Agent Skills](https://github.com/addyosmani/agent-skills)**, an SDLC-focused skills pack for coding agents.

## Positions (from sources in this wiki)

- **Agent configuration has a half-life.** Context files, skills, plugins, MCP servers, hooks, and memory accumulate by ratchet and should be audited every few weeks. See [Agent Configuration Audit](../concepts/agent-configuration-audit.md).
- **Pro-skills, but accepts the critiques.** Sees skills as a good abstraction for turning a generalist agent into a specialist, while conceding that skill packs often have thin descriptions and vague workflows and that evidence of net benefit is hard to produce for every workflow.
- **Archive before deleting.** Softens the "delete everything and rebuild" advice into archive → `/doctor` → remove → test without → decide.
- **Generic first, personal later.** Start from a strong community skill; don't promote a one-off preference into permanent memory.
- **Hard rules go in tests, hooks, or permissions**, not prose.
