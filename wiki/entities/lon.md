# Lon (@Lon)

Independent practitioner and X author; wrote [The Inference Gap](../sources/the-inference-gap.md) (2026-09-19). Heavy Claude Code user who, after perceiving a quality drop with Fable 5, minified-source-dived Claude Code (from July 30, 2026), built a semantically aware wire-capture proxy (first version August 1), and spent six weeks reconstructing wire logs and transcripts into the dataset behind the article. Names beyond the X handle are not given in the source.

Position: inference effort and regime are "the most consequential performance-bearing resource in AI"; providers should disclose realized reasoning distributions; under-deliberation is a safety and liability matter. Collection code was unreleased at publication; the author invited others with reasoning-token traces to replicate.
